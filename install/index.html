Install EzloPi

Flash an ESP32 board from this page over USB. No toolchain, no esptool, no Python.

This browser cannot talk to serial devices. Use Chrome, Edge or Opera on a desktop — Safari and Firefox do not implement the Web Serial API, and no mobile browser does. This page has to be served over HTTPS (or from localhost) before the browser will allow serial access.

Plug the board in first. The browser will ask you which serial port to use — that permission is per-site and you can revoke it at any time.

A 4 MB flash part is assumed on every target. The partition table allocates two roughly 2 MB application slots and cannot be shrunk. On a 2 MB board the flash will fail outright or the device will not boot.

Which chips this works on

The chip identifies itself over serial, so there is one button rather than four and the right image is chosen for you. What has actually been tried differs by chip, and that is worth knowing before you flash:

Target Builds in CI Flashed and booted by a human
ESP32yesyes
ESP32-S2yesno
ESP32-S3yesno
ESP32-C3yesno

For three of the four, all that has been demonstrated is that the firmware links and the image is well formed. Treat those as untested rather than broken — and please report what happens if you try one.

After flashing

This page does not set up Wi-Fi yet. ESP Web Tools does that over Improv Serial, and the firmware currently speaks Improv over Bluetooth only, so the install finishes and hands you straight back. Set the board up by:

  1. the EzloPi mobile app, which provisions over Bluetooth; or
  2. the serial console at 115200 baud, which prints the boot log and the device identity.

In-browser Wi-Fi setup arrives with the Improv Serial transport. At that point this page gains it with no change other than removing one line from the manifest.

What this is not

config.ezlopi.com is the hosted configurator: it flashes a binary Ezlo maintains and then walks you through describing your wiring. For most people that is the better starting point and this page does not replace it.

This page flashes the binaries built by CI from a specific commit of the source tree, which is what you want if you are running a fork, a patched tree, or one of the three targets the hosted configurator does not offer.

Built from ezloteam/Ezlo_Pi at __VERSION__. Nothing is uploaded anywhere: the image is fetched from this page's own origin and written straight to the board by your browser.
